# Figure 1 | Design and workflow of iDGRM 2.0.0

**a, Software architecture.** User-prepared duplicate pairs, comparable integer copy counts, whole-gene counts, TPM and biological-library/tissue metadata enter the four-class workflow. The recommended count route calls R/DESeq2 for a within-tissue paired negative-binomial model (`~ biological_library + copy`). Default directional evidence requires BH-adjusted P ≤0.05 and |log2 fold change| ≥1, with activity and valid-test filtering. TPM supports activity assessment. Completed differential tests can also be imported, or a separate log-expression paired t-test route can be selected. Reliable copy assignment and comparable observability are input prerequisites; iDGRM does not implement RNA-seq alignment or read-swap correction.

**b, Cross-tissue decision rules.** Profiles show arbitrary illustrative expression values across four tissues, not measured biological observations. Blue circles/solid lines denote copy 1 and rose squares/dashed lines denote copy 2. Sub-/neofunctionalized pairs show significant dominance of each copy in at least one tissue each. Asymmetrically expressed pairs show one-copy dominance in at least ceil(N/3) evaluable active tissues without significant reversal. No difference is the residual class when neither rule is met. The compatibility class Unmappable includes insufficient callable evidence (default N<2); it does not independently establish mapping status. Significance is encoded in the illustrative rule inputs, not estimated from these curves. SUB and NEO remain combined in all software outputs.

The framework is adapted from Lan and Pritchard (2016; DOI: 10.1126/science.aad8411), with the documented statistical adaptations of iDGRM. This schematic contains no empirical n, accuracy estimates or measured P values. Its rule checks verify code behavior, not biological classification performance.

## Figure contract and exports

The figure explains how one supported four-class workflow converts tissue evidence into reproducible labels. It is a schematic composite with architecture (a) and illustrative decision rules (b), drawn entirely with Python/Matplotlib on a white 183×180-mm canvas. Editable SVG, embedded TrueType PDF, 300-dpi PNG, 600-dpi LZW TIFF and a small preview are generated by `scripts/plot_fig1_idgrm_design.py`. The source illustration values and layout QA accompany the figure. No dataset-derived statistical conclusion is intended.

To redraw the optional documentation figure, install Matplotlib in an environment with iDGRM's Python dependencies, then run `python scripts/plot_fig1_idgrm_design.py --output-dir figures/Fig1_iDGRM_design`. Matplotlib is a figure-generation dependency, not a runtime dependency of the classifier.
