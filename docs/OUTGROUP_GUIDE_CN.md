# 外群选择、输入及推断边界

## 用户与软件责任

用户负责选择物种、判断正交关系与组织可比性。软件负责公开规则、验证输入和记录来源，不自动认证物种合理性、推断真实祖先或验证用户 QC 声明。所有结果为表达演化候选，不是蛋白质功能或祖先状态的直接证明。

## 选择外群

1. 先明确目标重复事件的大致系统发育位置；优先选择在该事件之前分化、仍保留相关单拷贝正交基因的近缘谱系。不是遗传距离最近就一定合适。
2. 优先高质量参考与完整注释，核对基因树、序列及可用共线性。外群自身复制、缺失、注释断裂或歧义关系不得按“单拷贝祖先”处理。
3. 尽量匹配组织、发育阶段、处理、性别和取样环境。根与根、相似发育期与相似发育期的比较比仅名字相同可靠；近似对应要明确标注。
4. 同一外群只是一份祖先状态代理；自身表达演化仍可能导致错误极化。多外群或实验验证可后续增加，不是本版必需条件。

## 必需输入

表达矩阵：首列基因 ID，其他列为样本 TPM。样本表：sample_id、tissue；必须是独立生物学重复，技术重复先合并。参考版本和基因 ID 须一致。

orthologs.tsv：pair_id、outgroup_gene_id、relationship。relationship 为 single_copy 或 ambiguous；歧义或未提供关系输出 UNRESOLVED，不猜测。同一 pair 只能一行；多个候选外群 copy 请声明 ambiguous，不要随意挑表达最高者。不同 pair 可共享同一外群基因（例如较大家族的多个重复对），软件不会误要求全局一对一；应评估家族历史。

tissue_map.tsv：target_tissue、outgroup_tissue、match_quality（exact / approximate）。组织对应须一对一，防止复用一个外群组织制造重复证据；近似对应默认不使用。未提供的组织不参与极化。

detection_qc.tsv：outgroup_gene_id、outgroup_tissue、assessment（adequate / inadequate）。adequate 表示用户已检查该基因模型、可定量性、文库深度与整体 QC，认为该组织可用于检测该基因，而非“已经证明无表达”。未声明或 inadequate 的组合一律 UNKNOWN。

QC 声明尤其需要避免：缺失基因填零、无对应组织填零、比对失败填零、几乎不可唯一归属的基因误认成低表达。即使声明 adequate，低 TPM 也只是当前实验的低检测状态，不是绝对不表达。

## 输出及阈值

输出保留全部基础 pair，只有 SUB/NEO 进入候选极化；其他为 NOT_ELIGIBLE。外群缺失、关系歧义、对应不足或混合信号为 UNRESOLVED。单独输出逐组织 ON/OFF/UNKNOWN 和 QC，且不覆盖基础分类。

默认 ON=1 TPM，OFF=0.1 TPM，每组织至少两重复、至少两匹配有效组织、保留覆盖比例=0.8。建议三重复或以上；可通过命令行修改阈值并比较候选标签敏感性。阈值不是已校准的机制准确率，不输出置信概率。

默认还要求状态完整组织占已纳入匹配组织的比例至少 50%（--minimum-informative-fraction）；不能只从大量 UNKNOWN 中挑出两条支持记录。该比例不包含用户未提供的组织，因此仍须报告整体取样范围。

实际分析应报告纳入和排除的组织数、状态完整比例、外群来源、正交关系来源，以及改变合理阈值后标签是否稳定。不能用候选数量多作为判定正确的依据。
